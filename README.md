evictf is a shellscript for automating cleanup of files downloaded locally from iCloud Drive via the macOS bird process (brctl). 

The Optimize Mac Storage feature seemed to be unpredictable and I was spending too much time chasing down stray files and folders taking up space on my SSD. For those of us with iCloud storage larger than our local disks, there needs to be a one-click option to recursively go through local folders and clean out what's not being used. Until that feature is built into the OS, this is a solution. Simply navigate to the head folder you want to evict, run the script, and it will take care of the rest. 

The only conditions I had for this code were that it save me time, and not cause problems. It's not fancy but should have enough protections that it is safe to use.
